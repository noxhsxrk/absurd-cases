ย้ายมาจาก SKILL.md แบบคำต่อคำเมื่อ 2026-11-16 (ไม่ได้แก้เนื้อหา) — ถ้าไฟล์นี้ขัดกับ `SKILL.md` ให้ยึด `SKILL.md`; ไฟล์นี้คือรายละเอียด เหตุผล และประวัติของกฎ

**ถูกทับแล้วในไฟล์นี้**: "เขียน 8–14 บรรทัด" → 9–12 บรรทัด ≤ 88 พยางค์ · "เขียน series_bible เพิ่ม" ตอนเขียนบท → bible เขียนตอนส่งงาน (ขั้น G) · `script.json` เขียนเมื่อเสียงเข้าแล้ว (ขั้น B) และ `titleCard` เป็นแค่บันทึก ข้อความป้ายอยู่ใน `Episode.tsx` · `tools/tts/gemini_tts.py` ใช้เฉพาะเมื่อ Nox สั่ง

## 1. ไอเดีย → สคริปต์ (`episodes/absurd-cases/epN_script.json`)
1. เริ่มจาก **มุกปิด** ก่อน (pun ไทยหรือ callback จากตอนก่อน) แล้วเดินถอยหลังหาข้อหาและผู้ต้องหา
2. เขียน 8–14 บรรทัด ภาษาพูดสั้น อดีตกาล deadpan แปลตามบริบทให้เป็นธรรมชาติ ไม่แปลตรงตัว (ข้อหา: ทำร้ายร่างกาย บุกรุก ลักทรัพย์ หมิ่นประมาท ขับขี่ประมาท พยายามฆ่า กักขังหน่วงเหนี่ยว ละเมิดลิขสิทธิ์ …)
3. ทุกบรรทัด: `id`, `text`, `cards` = [[ข้อความการ์ด, คีย์เวิร์ด], …] (2–5 คำ/การ์ด) และ `titleCard` ตรงบรรทัดข้อหา; เสียงของผู้ต้องหาใส่เป็น `after` (SFX + การ์ด) ไม่ใช่บรรทัดพากย์
4. เขียน `series_bible.md` เพิ่ม: hook ที่ปลูกไว้ให้ตอนหน้า, ของที่ใช้ซ้ำ (ชุดคุกเบอร์ 18/19/20, ศาล, โหลหลักฐาน)
5. ส่งให้ Nox เฉพาะ **ข้อความพากย์ล้วน** (`epN_script.txt`) + `voice_prompt.md` — เขาเจนเสียงเองใน Google AI Studio เสียง **Fenrir** (prompt ที่มีอารมณ์กว่า deadpan ล้วนอยู่ใน voice_prompt.md) ห้ามไปหา API key ในเครื่อง/ไฟล์ (ค่าเริ่มต้นคือ Nox เจนเองแล้วส่งไฟล์มา เช่น EP14–16; `tools/tts/gemini_tts.py --episode N` ใช้เฉพาะเมื่อ Nox สั่งให้เจนแทน)

### 1-R. เมนูเล่าเรื่องจาก ref6 (ใช้ตอนคิดเรื่อง ก่อนเขียนบรรทัดแรก)
- **เลือกโครง 1 แบบ (อย่าใช้ "จับ → ศาล → คุก → พ้นโทษ" ตรงๆ ซ้ำ):**
  1. *เกินเหตุ + ลูกหลง*: เปลี่ยนผู้รับสาย (กองทัพ ยามฝั่ง อินเตอร์โพล) แล้วไต่ 3 ขั้นด้วยประโยคสั้น 3 ประโยค ("โดนพายุ / โดนหมู่บ้านด้วย / ทั้งหมู่บ้าน")
  2. *ผู้ต้องสงสัยผิดตัว → ตัวจริง*: สอบสวนของที่เห็นชัดสุดก่อน ("มันไม่ยอมพูด") ตัวจริงมาจากนอกแนว ปูไว้ตั้งแต่ช็อตที่ 2 และโชว์ภาพก่อนเอ่ยชื่อ 15–20 เฟรม
  3. *ข้อหาที่ไม่มีความผิด ตำรวจคือตัวตลก*: "มันยังไม่ได้ทำอะไร นั่นแหละน่าสงสัย" เรียกพฤติกรรมธรรมชาติด้วยกริยามนุษย์เป็นทอด (ฟ้าร้อง = "มีการยิง", ฝน = "ร้องไห้", เมฆขาว = "ผู้บริสุทธิ์") ผลกรรมตกที่เจ้าหน้าที่ (เข้าบำบัด) ไม่มีใครติดคุก
  4. *คนที่สามเถียงสูตร แล้วกลายเป็นผู้ต้องหา*: ประโยคประจำถูกตัดกลางคำโดยตัวละครใหม่ ("นี่ไม่ใช่ทำร้ายร่างกาย นี่คือวิทยาศาสตร์") ความน่ารำคาญกลายเป็นข้อหาที่สอง
  5. *กลับบทบาท*: ผู้ต้องหาเป็นฝ่ายเห็นชายคนนี้ทำผิดเล็กน้อย แล้ว "โทรแจ้งตำรวจ" เอง ชายคนนี้ได้โทษเท่าเดิม ห้องขังเดิม
  6. *ภาคต่อเป็นองก์* (ตอนพิเศษ ~60 วิ): สูตรจบใน ~16 วิ แล้วองก์ละ 1 คู่ประโยค (ปู + เก็บ, 3–5 วิ, 2–3 ช็อต) ผลขององก์นี้เป็นจุดเริ่มขององก์ถัดไป (คุก → แหกคุก → "ประพฤติดี" → ปล่อยก่อนกำหนด → บริการชุมชน → ก่อเหตุใหม่ → หนีออกนอก → ประกาศจับ)
  7. *"ขณะเดียวกัน"*: เหตุการณ์ของอีกตอนเป็นเหตุให้ตำรวจไม่ว่าง (ตอนจับโลก = ทุกนายติดงาน) ผู้ต้องหาของตอนนี้เลยรอด
  8. *ตอบโต้เล็กเกิน*: ตำรวจ 2 นาย สอบสวนขวดนมแบบตำรวจดี-ตำรวจร้าย; การจับ "คน" ทำให้เล็กและเร็ว (เทคเดียว ~2 วิ) เทียบกับความอลังการที่ให้ธรรมชาติ
- **ประโยคประจำเป็นของเล่น**: ตัดกลางคำ / เปลี่ยนผู้รับสาย / ผู้ต้องหาเป็นคนโทร / โทรรอบสองด้วยข้อหาใหม่ — ตอนหนึ่งเล่นได้ 1 แบบ
- **ประโยค**: เฉลี่ย 4–5 คำต่อประโยค (ต้นฉบับ 49–74 คำใน 21–28 วิ) ชุดสามประโยคสั้นใช้ไต่ระดับ; แนะนำทีมแบบหนังปล้น ("ดวงอาทิตย์มีแว่นขยาย เมฆมีที่กำบัง ขาดแค่ตัวล่อ")
- **โทษ = งานที่ตรงกับธรรมชาติของผู้ต้องหา** (พายุหมุนปั่นกังหันลม มีตำรวจถือแส้คุม; เมฆรดน้ำทุกสวน) และ **สิ่งที่ "ขาด" ตอนต้นเรื่องกลับมาเป็นโทษแบบคูณ** (ป้ายพื้นเปียกที่ไม่ได้ตั้ง → ป้าย 35 อันเต็มถนน)
- **มุกปิด 6 แบบ — เลือก 1 และห้ามซ้ำแบบกับ 2 ตอนก่อน** (EP10–13 จบ "พ้นโทษมา … อาชีพใหม่" ติดกัน 4 ตอน):
  (ก) ย้อนหาเหยื่อที่คนดูลืม ("อ้อ หมาตายแล้ว") · (ข) ผลกรรมแห้งๆ ที่เจ้าหน้าที่ ("เขาเข้าบำบัดมาจนทุกวันนี้") · (ค) ผลตรงตัว 3–4 คำ ("เขาไม่ฉลาดอีกแล้ว") · (ง) สมมาตร/กลับบทบาท ("เขาได้สิบปี คลื่นใช้สิบปีนั้นที่ชายหาด กับครอบครัว") · (จ) ภัยยังลอยนวล วนกลับฉากเปิด ("พบล่าสุด กำลังตามชายคนนี้") · (ฉ) มุกภาพเงียบ 1.6–3.5 วิ หลังประโยคสุดท้าย ไม่มีซับ (ผู้ต้องหาทำผิดซ้ำในรถตำรวจ)
- **เขียนช่องเงียบลงในบท**: 3–7 จังหวะภาพล้วน (0.4–1.3 วิ) หลังประโยคที่ผลของมุกต้องค้างให้ดู; ก่อนประโยคเฉลย ค้างภาพเงียบ ~24 เฟรม
- **จักรวาลเดียวกันแบบจับต้องได้**: เหตุการณ์เดียวเล่าจากฝั่งของแต่ละตัวในตอนของมันเอง; เลขห้องขัง/ป้ายเดิม; ของประกอบชิ้นแรกของตอนกลับมาหลายหน้าที่ (ของแต่งฉาก ×45, เอกสาร, ไอคอน, ป้าย, ตัวปิดฉาก)
- คำพูดตัวละครในเครื่องหมายคำพูด 0–3 ประโยคต่อตอนใช้ได้ ("มีการยิง!", "คุณฉลาดไหม" "ฉลาดมาก")

## 4-S. กฎการเล่าจากคอมเมนต์ Nox (EP8 — ใช้กับทุกตอน)
- **เวอร์เกินจริงคือเครื่องยนต์ (Nox EP14: "ไม่ต้องคิดถึงความเป็นจริงขนาดนั้น … เน้นเวอร์ๆ" + ref6)**: ขนาดและฟิสิกส์ของโลกไม่ต้องสมจริง (รถสายตรวจพ่นไฟบินออกอวกาศไปใส่กุญแจมือโลก, เจ็ตยิงทั้งหมู่บ้าน, ยิงฟ้า 600 นัด) กฎข้อ "ฟิสิกส์สมเหตุสมผล / จัดการตรงที่มันอยู่จริง" ด้านล่างหมายถึง *ตรรกะภายในของมุก* และ *ภาพอ่านออก* เท่านั้น ถ้าเวอร์ชันสมจริงกับเวอร์ชันเวอร์ให้เลือกเวอร์
- **ของอยู่ปกติของมัน คนต่างหากที่เวอร์ (Nox EP15: "ของมันก็อยู่ปกติของมัน แต่ไอ้ทุกคนคือทำมันให้เวอร์")**: ผู้ต้องหาทำแค่สิ่งที่มันทำจริงตามธรรมชาติ ห้ามแก้พฤติกรรมของมันให้เข้ากับมุก (ดวงจันทร์ไม่ได้วิ่งตามรถ — มันลอยอยู่ที่เดิม ไกลมาก เลย *ดูเหมือน* ตาม) ความเวอร์ทั้งหมดใส่ที่คน: คำกล่าวหาของชายคนนี้ การตอบโต้ของตำรวจ คำสั่งศาล และ **ตำรวจเป็นฝ่ายไปหาผู้ต้องหาถึงที่แบบเวอร์** (รถสายตรวจบินออกอวกาศ 384,400 กม. ไปใส่กุญแจมือ) ไม่ใช่ตั้งด่านรอให้มันมาหา — EP15 v1 ทำกลับด้านทั้งสองข้อ ต้องรื้อ
- **เห็นโลกจริงรอบตัว**: ฉากเปิดต้องเห็นบ้านเรือน/ตึก (เช่น เดินเล่นในหมู่บ้านจัดสรร บ้านเดี่ยว รั้ว ประตู ต้นไม้ เสาไฟ) ไม่ใช่กำแพงเปล่า
- **เริ่มจากความปกติ**: ผู้ต้องหาทำสิ่งที่มันทำตามธรรมชาติ (เงาทอดตามปกติ) ไม่ต้องแสดงให้มัน "ทำผิด" เกินธรรมชาติ (ตัดช็อตเงาแอบย่องทิ้ง) — ความตลกมาจากตำรวจที่ทำตามตัวอักษร
- **ตำรวจจัดการกับผู้ต้องหาตรงที่มันอยู่จริง**: เงา = เงาที่ติดเท้าเขาอยู่ → SWAT ล้อมตัวเขากับเงา, สปอตไลต์หันส่อง *เงา* (ไม่ใช่กลางถนน), เกรียงแซะตรงส้นเท้า หลังจับเขายืนไม่มีเงา
- **ฟิสิกส์ของผู้ต้องหาต้องสมเหตุสมผลในตัว**: เงาไม่มีเงาของตัวเอง (castShadow ปิดทุกฉาก), ถูกสั่งให้ "บังแดด" = นอนแผ่เป็นร่มเงาให้คนยืนบนตัวมัน (คนที่ยืนบนเงาไม่มีเงาตัวเอง) ไม่ใช่ยืนทอดเงาซ้อนเงา
- **คนทำ = คนถือของ**: ผู้พิพากษาต้องถือค้อนแล้วทุบเอง (มือเห็นในช็อต CU) อย่าให้ของขยับเอง
- **เสียงต้องสมจริง**: AudioLDM2 (16 kHz) ไม่ผ่านสายตา Nox → ใช้ Stable Audio Open (§5)
