## Q. มาตรฐานคุณภาพ + ด่านอนุมัติ (บทเรียน EP8 — ห้ามข้าม)
EP8 รอบแรกโดน Nox ตีกลับว่า "ลวก" เพราะ: ส่ง render หลังดูแค่ still กลางช็อตละ 1 ภาพ, ไม่ได้ดูการเคลื่อนไหวทีละเฟรม, ผู้ต้องหา (เงา) ไม่ได้ look-dev แยกก่อนจึงเป็นตุ๊กตาดำ/แผ่นแข็ง, มีเสาบังตัวละคร, เงาบ้านทับเงาตัวเอก, ท่าย่อ/พับเขียนด้วยโค้ดเลยแข็ง. เป้าคุณภาพวัดจาก 5 คลิปที่ Nox ส่ง → `episodes/absurd-cases/ref5_visual_notes.md` (อ่านก่อนทุกตอน)

สรุปสิ่งที่ทำให้ต้นฉบับดูธรรมชาติ: เรนเดอร์ระดับเอนจิน (เงานุ่ม, AO ทุกซอก, แสงสะท้อน, bloom, ลำแสง+ฝุ่น, DOF ช็อตใกล้, motion blur ทุกการเคลื่อนไหวเร็ว, ผิวทุกชิ้นมีลายพู่กัน/เส้นหมึก) · การเคลื่อนไหวมีน้ำหนักจริง (mocap/ฟิสิกส์ — ลื่นล้มเป็นโค้ง หมุน กระแทก ไถล; คนยืนเฉยก็หันหัว ตานำ ease 8–12 เฟรม) · กล้องเหมือนมีตากล้องถือ (แพนตาม รีเฟรม ลงจอดนุ่ม) · 1 ช็อต = 1 แอ็กชัน จัดให้เลนส์ ไม่มีอะไรบัง · ผู้ต้องหาที่เป็นนามธรรมเล่าผ่านฟิสิกส์ของโลก ("the dark" = ไฟดับ/ช่องมืด ไม่ใช่หุ่นดำ)

**เป้าปริมาณ (Nox 2026-11-09): 3–4 คลิป/วัน** — ทำได้เพราะใช้ซ้ำได้มากแม้ผู้ต้องหาต่างกัน (เสียงจากคลัง §5, ฉาก/ตัวละคร/พร็อพซ้ำจาก kit three.js (`src/episodes/AbsurdEp1/sets`, `absurdkit`, props ของ EP3–7) งานใหม่ต่อตอนคือผู้ต้องหา + 1–3 ช็อตเด่น; ตอนละแชต ทำขนานกัน

ภาพทำด้วย three.js/Remotion เท่านั้น (§4)

ด่าน (ฉบับเร็ว — Nox อนุมัติให้ตัด QA ซ้ำซ้อน):
1. **Look-dev เฉพาะของใหม่** (ผู้ต้องหาใหม่/ฉากใหม่/ท่าใหม่) → ทำภาพนิ่ง/ช็อตทดสอบแล้วตัดสินใจเอง **ไม่ต้องหยุดรออนุมัติ** (Nox EP14: "ทำต่อเลยไม่ต้องถามผมแล้ว") จดทางเลือกไว้บอกตอนส่ง; ของในคลังที่อนุมัติแล้วไม่ต้องทำซ้ำ
2. **เช็กภาพย่อรายช็อต** (`pnpm exec remotion still`): ภาพ 25–40 % 2–3 เฟรมต่อช็อต (จุดเริ่ม/แอ็กชัน/จบ) — ห้ามข้ามข้อนี้ จับปัญหาได้เกือบทั้งหมด (ตัวบังเงา, เงาใต้เท้า, เฟรมหลุด) ใช้แค่ 1–2 นาที
3. **เรนเดอร์จริงรวดเดียวทั้งตอน** คุณภาพเต็ม (§6)
4. **QA รอบเดียวบนคลิปที่ประกอบเสร็จ** (contact sheet ทุก 8 เฟรม + ฟังมิกซ์) → แก้เฉพาะช็อตที่พัง → ส่ง Nox พร้อมรายการตรงๆ ว่าเหลืออะไร — ห้ามบอก "เสร็จ" ถ้ายังมีปัญหาที่รู้; ปัญหาที่รู้และแก้เองได้ให้แก้ก่อนส่ง (Nox EP16: "ทำต่อให้เสร็จ") รายการที่เหลือ = เฉพาะสิ่งที่ Nox ต้องตัดสิน หรือที่ตรวจเองไม่ได้ (เช่น ฟังเสียง)
- **ไม่ใช้ reviewer agent แยก** แล้ว (ตัดเพื่อความเร็ว)

## 7. QA checklist ก่อนส่ง
1. hook ใน 2 วิแรก เฟรม 0 อยู่กลางแอ็กชัน ไม่มีไตเติล
2. คลิป ≤ 30 วิ, ASL ~1.1–1.5 วิ, ไม่มีช็อต > 3.5 วิ, ทุกฉากดูเข้าใจโดยไม่ต้องฟัง (ใครทำอะไร เห็นผลของมุก), ซับอ่านทัน, ฉากที่เพิ่มมีบทพากย์รองรับ
3. มีครบ: สูตรตำรวจ (มีการโทรแจ้ง) / scale shot / ป้ายข้อหาห้อยหล่นตรงคำข้อหา (±2 เฟรม) / สถาบันหน้าตรง / ECU ของประกอบ / กุญแจมือยักษ์ / มุกปิด ≤ 5 คำ + ตอนจบตามแบบที่เลือก (§4d) / hook ตอนหน้า
4. มี BGM เบาๆ ใต้พากย์ (§5), −15 LUFS, พากย์ดังกว่าเสียงอื่น ≥ 8 dB ขณะพูด, SFX ตรงคัต, คำตอบผู้ต้องหาได้ยินชัด
5. ตัวละครไม่หาย (frustum), ป้าย 3D ไม่ดำ ไม่ลอย ไม่หลุดเฟรม, ซับไม่ทับป้าย, ชื่อแอคเคานต์ (`HANDLE` ใน data.ts) อยู่ในฉาก
6. ดูจากเฟรมไฟล์ render จริง ไม่ใช่ still อย่างเดียว
7. ไม่มีเฟรมนิ่ง: frame diff เฉลี่ย > 0.6 ทุกเฟรมยกเว้นตอนจบแบบค้างนิ่ง, ทุกช็อตมี push/pull ≥ 4 %/วิ หรือมีตัวละครขยับ, ช็อตเคลื่อนเร็วมี motion blur
8. แอนิเมชันตัวละคร: ทำ strip ทุกเฟรม (ครอปเต็มความละเอียดที่มือ/หน้า/เท้า) ทุกช่วงที่มีท่ามือ สัมผัส หรือเปลี่ยนคลิป เช็กว่า (ก) ไม่มีเฟรมที่ท่ากระโดด (ข) จุดสัมผัสชนพอดี (ค) นิ้วเปลี่ยนรูปตามงาน (ง) ยกเร็ว-ลงเร็วกว่า มีเลยเป้าแล้วนิ่ง (จ) ปากขยับเฉพาะบรรทัดของตัวเอง (ฉ) เท้าไม่ไถล
9. ผู้ต้องหาอ่านออกชัดทุกเฟรมที่ควรเห็น: ไม่มีเสา/คน/เงาวัตถุอื่นทับ, คอนทราสต์กับพื้นพอ (เช่น เงาบนพื้นสว่าง), ไม่บางเป็นเส้นเพราะมุมกล้อง
10. เทียบกับ ref5 ทีละหัวข้อ (แสง/เท็กซ์เจอร์/น้ำหนักการเคลื่อนไหว/กล้อง/staging) ตอน QA รอบเดียวบนคลิปที่ประกอบเสร็จ (ไม่ใช้ reviewer แยกแล้ว)
11. เสียง: ค้นคลัง (`search`) + `pull` ก่อนเจนใหม่; เสียงใหม่ทุกตัวต้องมีบรรทัดใน usage.json และผ่าน `publish` แล้ว (อยู่บนคลัง + index บน GitHub อัปเดต)
12. ref6: (ก) โครงเรื่องและแบบมุกปิดไม่ซ้ำ 2 ตอนก่อน (ข) ช่วงตอบโต้เกินเหตุ ~1/3 ของคลิป และเวอร์จริง (ค) ผู้ต้องหาไม่มีหน้า แสดงผ่านของประกอบ/ป้าย/สี (ง) มีจังหวะภาพเงียบ ≥ 3 (จ) ทุกการกระแทกลงคำเน้น ±1 เฟรม (ฉ) คัตนำเสียง 5–9 เฟรม (ช) ตอนจบเลือกแบบไว้แล้ว (นิ่ง / เดินต่อ / มุกภาพเงียบ)
13. EP15: (ก) ผู้ต้องหาทำแค่สิ่งที่มันทำจริง ความเวอร์อยู่ที่คน และตำรวจไปหามันถึงที่ (ข) ของไกลไม่ขยับในเฟรมเมื่อกล้องเคลื่อน (ค) ตัวแบบทุกช็อตอยู่เหนือแถบซับ ไม่มีของสำคัญสองชิ้นหลุดขอบซ้าย–ขวา (ง) ซับคมทุกเฟรมในไฟล์ motion blur

EP16: (ก) ผู้ต้องหานามธรรม (แรงโน้มถ่วง) ไม่วาดตัว เล่าด้วยของที่ตกจริง (½·9.8·t²) ก่อนโดนจับ ของที่ลอยหลังโดนจับ เส้นประแดงแบบ annotation และกุญแจมือล็อกอากาศ + ป้ายตอนถูกคุมตัว (ข) หลังเหตุพลิกโลก (ทุกอย่างลอย) ไม่มีของหลวมค้างบนพื้นหรือห้อยลง: ปิด `animals` ของ VillageLife, `Village lift` ยกทั้งแปลง, ป้ายลอยขึ้น (ค) ตัวเอกและรถตำรวจต้องอยู่ต่อเนื่องทุกช็อตของซีเควนซ์เดียวกัน อย่าให้หายไประหว่างคัต และอย่ายืนทับพร็อพใหญ่ (ปากหลุม ขาสามขา) (ง) แถวคน/ฝูงชนยาวให้กล้องเยื้องออกจากแกนแถว + สุ่มตำแหน่งและความสูงเล็กน้อย ไม่งั้นเป็นแถบสี (จ) 9:16 มองได้แค่ ~±15° แนวนอน: ของสองอย่างที่ต้องอยู่ข้างกันในห้องแคบถ้าใส่ไม่พอให้ตัดออก ดีกว่าครอปครึ่งตัว (ฉ) กับดักโค้ด: อย่าส่ง key ที่เป็น undefined เข้า `ps()` (เช่น poseId) เพราะทับค่าเริ่มต้น, `Puffs` วนไม่จบต้องจำกัดช่วงเวลาเอง, `label()` แคชตาม key ต้องใส่ค่าที่เปลี่ยนไว้ใน key (ช) ระหว่างรอเสียงพากย์: `premix` รันโหมดร่างได้ แล้ว mux ด้วย ffmpeg ให้ดูภาพพร้อมเสียงประกอบ; `tighten_take.py` เตือนเองถ้าจุดตัดอยู่ในเสียง (ซ) แขนห้ามจมในลำตัว (Nox: "แขนมันเข้าไปในตัวทุกคนเลย"): pole ของ `ik()` อยู่ในพิกัด root ที่ +x = ซ้ายของตัวละคร ศอกขวาต้องใช้ (−1, −1, −0.3) ศอกซ้าย (1, −1, −0.3); คลิป `idle_angry_01` (เท้าเอว) ทำมือกล่องจมลำตัวกล่อง ให้ใช้ `idle_neutral_01` แล้วให้หน้าเล่นอารมณ์; เช็กแขนทุกตัวจากภาพนิ่งระยะใกล้ก่อนส่ง (ฌ) ฉากโทร 191 อยู่บนมือถือ 3D ตลอด ไม่ใช้จอ `CallScreen` 2D เต็มจอแล้ว (Nox EP16) ใช้ punch-in ตอนกดแทน

EP17: (ก) ของเรืองแสง (ไฟ) ใกล้หน้าคน: point light ≤ ~1 และ Glow จาง ไม่งั้นเสื้อและหน้าขาวโพลน; ไฟในปากให้พุ่ง *ออกหน้า* (ทิศในเฟรมหัว `hdir(I, [0, 0.32, 0.95])`) แล้วตั้งกล้องเฉียง 3/4 อย่าให้พุ่งขึ้นทับตา; จุดบนหัว (ปาก หู) หาด้วย `hw()`/`hdir()` ใน `AbsurdEp17/shots.tsx` (ข) "ของสิบชิ้นพุ่งเข้าเป้าเดียว" ใน 9:16 = ช็อตมุมบน `roll0: 90` ให้ถนนวิ่งขึ้นเฟรม ไม่ใช่มุมระดับตาที่เห็นแค่สองลำ (ค) จำนวนที่พากย์เอ่ย ("สามคู่") ต้องนับได้ในเฟรม: ป้ายหลักฐานเลข 1–3 ข้างของแต่ละชิ้น (ง) ของที่คีบ/ถือให้อยู่ในช่องว่างระหว่างตัวละคร ไม่ใช่หน้าลำตัวคนถือ และคำนวณแนวกล้องไม่ให้เสาต้นไม้อยู่หลังของพอดี (จ) โต๊ะเหล็กห้องสอบสวนขาวโพลนใต้โคม: ช็อตใกล้บนโต๊ะให้ปูแผ่นรองสีเข้ม (ฉ) `tighten_take.py` เตือนจุดตัดอยู่ในเสียง: ขยาย range ออกข้างละ ~0.05 วิ หดช่องลูกน้ำข้างละ 0.04 แล้วเอาคืนด้วย inner 0.12 + ลด gap บรรทัดละ 0.1 (ช) SAO: เสียงไฟลุกออกมาทุ้มต่ำกว่า 150 Hz และเสียงไฟลุกค้างเป็นแค่เสียงแตกเปาะห่างๆ ให้ซ้อน synth ใน premix (`fwh`, `crk` ใน `premix_absurd_ep17.py`); BGM ของ SA3 มีช่วงเว้นเงียบทุก ~5 วิ เป็นปกติ เลือกเทคที่ช่วงเว้นสั้นสุด

**ทริกเกอร์**: Nox บอกชัดว่าคลิปตอนนั้นโอเคแล้ว ไม่ต้องปรับ/แก้แล้ว (เช่น "โอเค ปิดตอน", "ผ่านแล้ว ไม่ต้องแก้") — คำชมเฉพาะจุด ("ดีเลย", "good") ระหว่างยังแก้อยู่ **ไม่นับ**; ถ้าไม่แน่ใจให้ถามสั้นๆ ว่าปิดตอนนี้เลยไหม. พอได้ทริกเกอร์แล้วลบได้เลยไม่ต้องขออนุญาตซ้ำ แต่ทำเฉพาะตอนที่ Nox ปิด
- **ลบ** (ของตอนนั้นเท่านั้น):
  - คลิปเวอร์ชันเก่าใน `out/` (`absurd-epN-v1..` ทุกตัวยกเว้นตัวสุดท้ายที่ส่ง), เรนเดอร์รายช็อต, still/ภาพเช็ก (`out/check*.png` ฯลฯ), log เรนเดอร์
