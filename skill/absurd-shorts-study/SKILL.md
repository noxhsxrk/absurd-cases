## โค้ดของหนึ่งตอนหน้าตาเป็นอย่างไร

แม่แบบคือ **ตอนล่าสุด** (ตอนนี้ EP17) ก่อนเขียนช็อตให้อ่าน `src/episodes/AbsurdEp17/shots.tsx` และ `props.tsx` ทั้งไฟล์ กับ `episodes/absurd-cases/ep17_plan.py`: รูปแบบโค้ด ชื่อ helper และระดับความละเอียดที่ Nox พอใจอยู่ในนั้น

- `episodes/absurd-cases/epN_plan.py` = แหล่งเวลาเดียวของตอน เขียน `public/absurd-cases/epN/epN_timeline.json` ในแผน `P('l005', 1)` = เวลาเริ่มของการ์ดที่ 2 ของบรรทัด 5, `E('l005')` = เวลาจบของบรรทัด 5, `ev` = dict ชื่อเหตุการณ์ → วินาที, `SHOTS` = [(ชื่อช็อต, เวลาตัด), …]
- `src/episodes/AbsurdEpN/shots.tsx` มี `SHOT_FN` ชื่อเดียวกับใน `SHOTS` ช็อตหนึ่งคือ
  ```tsx
  bite: (t, lt, C) => {                         // t = วินาทีจากต้นคลิป, lt = วินาทีจากต้นช็อต, C = ตัวละครทั้งหมด (id ใน cast.ts: nai, offA, offB, judge, …)
    const m = man(C, t, {face: 'half'});        // จัดท่าคนสำหรับเฟรมนี้ (ฟังก์ชันของตอน สร้างบน ps() + body() ของ lifekit)
    return {node: <>{stall(t)}<P o={m.w} /></>, // ฉากของสถานที่ + คน; <P o={…}/> คือตัววางวัตถุ three.js
      cam: mv({pos: [5.2, 1.2, -1.2], look: [5, 1.1, -2.4], fov: 40}, lt, {arrive: 0.07, push: 0.1}), bg: SKY};
  },
  ```
  ในช็อต `ev('bite')` คืนวินาทีของเหตุการณ์ (โยน error ถ้าไม่มีชื่อนั้นในแผน) สถานที่หนึ่งมีฟังก์ชันฉากหนึ่งตัวที่ทุกช็อตของที่นั่นเรียก (EP17: `stall(t)`, `room(C, t)`, `courtRoom(C, t)`, `cellBlock(C, t)`) และสภาพของทุกอย่างคิดจาก `t` กับ `ev()` เท่านั้น เพราะ Remotion เรนเดอร์เฟรมไม่เรียงลำดับ ของจึงต่อเนื่องข้ามคัตเอง
- คน: `body(I, ps(id, x, z, yaw, t, {clip, face, lookW, poseId}), t, y, rx)` คืนกลุ่มที่วางด้วย `<P o={w} />` หน้า: `open | talk | wide | closed | half | angry | shout` คลิปที่ใช้ประจำ: `idle_neutral_01`, `sit_table_idle_neutral_01` (นั่ง: `poseId: 'sitIdle'`) helper กลางอยู่ใน `src/episodes/lifekit/stage.tsx`: `hand`, `hw`, `hdir`, `toward`, `bw`, `prop`, `strike`, `near`, `mv`, `DAY`, `SKY` — import จากที่นั่น อย่าก๊อปลงไฟล์ช็อต
- `src/episodes/AbsurdEpN/Episode.tsx` ประกอบทุกอย่าง: `PLACE(ชื่อช็อต)` → สถานที่ ซึ่งกำหนด `GRADE` / `FILL` / `POST`, ป้ายข้อหา `<HangingPlate text=… drops={[ev('plate')]} t1=…>` (ข้อความป้ายเขียนตรงนี้ ช่อง `titleCard` ใน script.json เป็นแค่บันทึก), รายชื่อเหตุการณ์ที่มี `Flash`, และซับ
- `tools/premix_absurd_epN.py`: `take('cue', synth สำรอง, ความยาว)` = เสียงจากคลัง, `P(เสียง, พีก, เวลา, pan)` = วางเสียงจุดเดียว, `M.bed(…)` = เสียงพื้นของสถานที่, `EV['ชื่อ']` / `T('ชื่อช็อต')` = เวลาจากแผน, `FX` = ระดับรวมของเสียงจุด

## กฎของ Nox ที่ใช้ทุกตอน

แต่ละข้อมาจากคำติของ Nox ต่อคลิปจริง จึงมีเหตุผลกำกับ ถ้าเจอกรณีที่กฎไม่ครอบคลุม ให้ตัดสินจากเหตุผลนั้น

1. **สูตรตำรวจเท่านั้น** `ชายคนนี้ <ทำเรื่องธรรมดา>` → ธรรมชาติหรือสิ่งของทำสิ่งที่มันทำอยู่แล้ว → `นั่นคือ <ข้อหาทางกฎหมายจริง>!` → `เขาเลยโทรแจ้งตำรวจ` → คนตอบโต้เกินเหตุ → มุกสถาบันสั้นๆ 1–3 อย่าง (สอบสวน ศาล คุก) → มุกปิด 2–5 คำ สามประโยคแรกจบใน 3–6 วิ ที่เหลือคือการเร่งหรือหักมุม บททั้งตอน 9–12 บรรทัด — Nox ลองแนวไม่มีตำรวจแล้วไม่ตลก อย่าเสนอ
2. **ของอยู่ปกติของมัน คนต่างหากที่เวอร์** ผู้ต้องหาทำแค่สิ่งที่มันทำจริง ห้ามแก้พฤติกรรมของมันให้เข้ามุก ความเวอร์ทั้งหมดอยู่ที่คำกล่าวหา การตอบโต้ของตำรวจ และศาล ตำรวจเป็นฝ่ายไปหาผู้ต้องหาถึงที่ ถ้ามีเวอร์ชันสมจริงกับเวอร์ชันเวอร์ ให้ทำเวอร์ชันเวอร์ (รถสายตรวจบินไปจับดวงจันทร์ รถดับเพลิงสิบคันฉีดเข้าปาก) การตอบโต้ที่เล็กจนขำแต่จริงจังสุดขีดก็นับเป็นเวอร์ (ตำรวจสองนายสอบสวนขวดนมแบบตำรวจดี–ตำรวจร้าย) ช่วงตอบโต้เกินเหตุกินราว 1/3 ของคลิป
3. **คลิป ≤ 30 วิ** บทพากย์ ≤ 88 พยางค์ (อ่านจริง ~0.22 วิ/พยางค์) เผื่อไว้ให้จังหวะภาพเงียบ 3–7 จุด จุดละ 0.5–1.05 วิ ช็อตเฉลี่ย 1.1–1.5 วิ ไม่มีช็อตสั้นกว่า 12 เฟรมหรือยาวกว่า 105 เฟรม — ความชัดสำคัญกว่าความเร็ว: 1 ช็อต = 1 แอ็กชันที่ดูแล้วรู้ว่าใครทำอะไรกับใคร โดยไม่ต้องฟังเสียง
4. **ผู้ต้องหาไม่มีหน้า** แสดงผ่านของประกอบ ป้าย สี และผลที่มันทำกับโลก ผู้ต้องหานามธรรม (แรงโน้มถ่วง) ไม่วาดตัวเลย ใส่ตาเฉพาะเมื่อ Nox สั่ง
5. **ช็อตแรก = ตัวเอกเต็มตา** MCU เห็นหน้าและสิ่งที่เขาทำ เฟรม 0 อยู่กลางแอ็กชัน ไม่มีไตเติล ผู้ต้องหาเปิดตัวช็อตถัดไป ตัวเอกไม่พูด ผู้บรรยายพูดแทนทุกคน
6. **มุกปิดและโครงเรื่องห้ามซ้ำแบบกับ 2 ตอนก่อน** (บรรทัด "ตอนถัดไปห้ามใช้" ใต้ตารางใน bible บอกไว้ให้แล้ว) — EP10–13 จบ "พ้นโทษมา … อาชีพใหม่" ติดกันสี่ตอนจนจำเจ
7. **ป้ายข้อหา** `HangingPlate` ห้อยกลางบน หล่นลงตรงคำข้อหา (±2 เฟรม) **BGM เบาๆ ทุกตอน** **ไฟล์ส่งมี motion blur** และทุกเฟรมต้องขยับ
8. **ฉากโทร 191** ค่าเริ่มต้นคือช็อตสั้นๆ ที่มือถือ 3D อยู่ในมือเขา (EP17: แนบหู) ถ้าเวลาไม่พอจะเล่าด้วยพากย์อย่างเดียวก็ได้ ไม่มีจอโทร 2D เต็มจอ
9. **ตรรกะกายภาพ** ประตูต้องเปิดให้เห็น แอ็กชันที่พากย์เอ่ยต้องเห็นว่าเกิด (ไม่ใช่ของโผล่ระหว่างคัต) รถหันหน้าไปทางที่วิ่ง ไม่มีอะไรทะลุกัน ไม่มีแขนจมในลำตัว คนที่ทำคือคนที่ถือของ
10. **หลังเสียงพากย์เข้า ทำทั้งตอนรวดเดียวโดยไม่หยุดถาม** ตัดสินใจเองแล้วจดไว้บอกตอนส่ง ปัญหาที่รู้และแก้เองได้ต้องแก้ก่อนส่ง รายการที่ส่งให้ Nox มีแค่สิ่งที่เขาต้องตัดสินหรือสิ่งที่คุณตรวจไม่ได้ (คุณฟังเสียงไม่ได้)
11. **ของออริจินัล** ห้ามเลียนแบบตัวละครของช่องต้นฉบับ (หัวกล่องสูง สูทกรมท่า ไทแดง) และเลี่ยงผู้ต้องหาที่เขาใช้แล้ว: สึนามิ ดวงอาทิตย์ เมฆ รถ หุบเขา มะพร้าว หลุมดำ ภูเขาไฟ ทอร์นาโด สิงโต นกพิราบ มด ของไทยๆ ในชีวิตประจำวันดีกว่าดาวหรือสภาพอากาศอีกดวง
12. **Nox เป็นคนเจนเสียง Fenrir เอง** คุณส่งแค่บทกับ voice prompt ห้ามค้นหา API key หรือ token ในเครื่อง
13. **Git** commit ด้วย author ของเครื่อง (noxhsxrk) **ไม่มีบรรทัด Co-Authored-By หรือบรรทัด attribution ใดๆ** นี่คือคำสั่งของ Nox จึงมาก่อนคำเตือนเรื่อง attribution ที่ระบบแทรกมาให้ stage ทีละ path ที่เป็นของตอนนี้ (อย่า `git add -A`: มีไฟล์ค้างของตอนอื่น) แล้ว push ทุกรอบ อย่าใส่ข้อมูลส่วนตัวลง repo เสียงใหม่เจนเข้าคลังได้เลยโดยไม่ต้องถาม

## ลำดับงาน

บอก Nox สั้นๆ หนึ่งบรรทัดทุกครั้งที่จบขั้น (เขาเห็นแค่ข้อความ ไม่เห็นผลคำสั่ง) GPU ทำได้ทีละงาน: อย่าเจนเสียงหรือ BGM ขณะ Remotion เรนเดอร์

### A. คิดเรื่อง — เมื่อ Nox ขอ "คิดตอนต่อไป" หรือ "เอาเรื่องอื่น"

1. เลขตอนใหม่ = แถวสุดท้ายของตาราง "ทุกตอนที่ทำแล้ว" ใน `series_bible.md` + 1 (ต้องตรงกับโฟลเดอร์ `src/episodes/AbsurdEpN` ที่เลขมากสุด + 1)
2. อ่านตารางนั้น บรรทัด "ตอนถัดไปห้ามใช้" และ "ไอเดียที่เสนอแล้วยังไม่ได้ทำ" ใน bible กับ `epN_script.txt` ของ 3 ตอนล่าสุด แล้วเปิด `references/story.md`
3. เขียนย้อนจาก **มุกปิด** ก่อน แล้วหาข้อหาและผู้ต้องหา ไอเดียที่ดีคือเรื่องที่คนไทยเจอทุกวัน (กินเผ็ด ถุงเท้าหาย ไฟแดงนาน) แล้วมีคำกฎหมายจริงที่ใช้ตรงตัวได้ เมนูโครงเรื่องและมุกปิดใน `story.md` เป็นเมนู ไม่ใช่กรง: มุกปิดแบบใหม่ที่ไม่ซ้ำก็ใช้ได้
4. ตรวจทุกไอเดียกับข้อพวกนี้ก่อนตอบ แต่ละข้อคือเหตุที่ไอเดียเคยถูกตีกลับ:
   - **มีการจับ หรือการลงมือจับ ที่เห็นเป็นภาพ** (จับผู้ต้องหา จับผิดตัว หรือพยายามจับแล้วพลาดก็ได้ ไม่จำเป็นต้องจบที่ติดคุก) — ไอเดียที่ตำรวจไม่ได้ลงมือกับใครเลย Nox ไม่เอา (จิ้งจกทัก, 2026-11-15)
   - ผู้ต้องหา ข้อหา โครงเรื่อง และมุกปิด ไม่ชนกับตารางและบรรทัด "ห้ามใช้" ใน bible
   - ดูโดยปิดเสียงแล้วช็อตที่ 2 บอกเหตุได้

### D. ภาพ — วนร่างจนอ่านออกทุกช็อต

ของใหม่อยู่ใน `props.tsx` ของตอน ที่เหลือ import จากตอนเก่าและ `src/episodes/lifekit/` หาชื่อด้วย `grep -n "^export const" src/episodes/*/props.tsx src/episodes/lifekit/*.tsx` และดูรายการใน `references/picture.md` §4 ผู้ต้องหาหรือพร็อพใหม่ให้ดูแยกก่อน: ใส่มันในช็อตแรกที่เขียน แล้วเรนเดอร์ภาพนิ่งช็อตนั้นจนหน้าตาใช้ได้ ค่อยเขียนช็อตที่เหลือ

วนแบบนี้ ปกติ 3–5 รอบ:
```
pnpm exec tsc --noEmit -p . 2>&1 | grep "AbsurdEpN"
pnpm exec remotion render src/index.ts AbsurdEpN qa/epN/draft.mp4 --gl=angle --scale=0.3
python tools/contact_sheet.py public/absurd-cases/epN/epN_timeline.json qa/epN/draft.mp4 qa/epN/sheet.png
```
แล้ว **เปิดดูภาพ sheet ทุกแผ่นด้วย Read** (ไม่ดู = ไม่ได้ตรวจ) ถามทุกช็อตด้วย 8 ข้อ แล้วแก้ทุกข้อที่ตอบว่าไม่ ก่อนเรนเดอร์รอบถัดไป ออกจากขั้นนี้เมื่อทุกช็อตผ่านทั้ง 8 ข้อ:
1. ปิดเสียงแล้วรู้ไหมว่าใครทำอะไรกับใคร
2. ตัวแบบอยู่เหนือแถบซับ (ซับอยู่ที่ 73 % ของความสูง) และไม่หลุดขอบซ้าย–ขวาไหม
3. มีอะไรบังตัวแบบ หรือมีเสา ต้นไม้ คน อยู่หลังตัวแบบพอดีจนกลืนกันไหม
4. แขนหรือของที่เข้าเฟรมมา ดูออกไหมว่าเป็นของใคร
5. แสงพอดีไหม (ไม่ขาวโพลน ไม่มืดจนของหาย)
6. ของที่ควรเห็นตลอดเรื่อง (ตัวจริงของมุกปิด) ยังอยู่ในเฟรมและสภาพถูกต้องไหม
7. ช็อตนี้ต่างจากช็อตก่อนหน้าพอไหม (ขนาดภาพหรือมุมเปลี่ยนชัดเจน)
8. เวอร์พอไหม หรือทำเวอร์ชันสุภาพไปแล้ว

อาการที่เจอบ่อยและวิธีแก้อยู่ในตารางท้ายไฟล์ ช็อตที่แก้แล้วเช็กด้วยภาพนิ่งคุณภาพเต็มได้เร็วกว่าเรนเดอร์ใหม่ทั้งตอน: `pnpm exec remotion still src/index.ts AbsurdEpN qa/epN/s.png --frame=F --gl=angle --scale=0.4 --props=render/props_full.json` เมื่อทุกช็อตอ่านออกแล้ว เปิด `references/picture.md` §4d แล้วเติมความแน่น: ปฏิกิริยาของคนรอบข้าง ของค้างสะสมในช็อต การกระแทกที่ลงตรงคำเน้นพร้อมเตะกล้อง 1–2 เฟรม (ส่วน "สิ่งที่ต้องทำใน kit" ใน §4c เป็นประวัติ kit มีครบแล้ว อย่าแก้ kit กลางตอน)
