# ในเมืองนี้ — series bible (ซีรีส์ใหม่ แยกจาก absurd-cases ไม่ใช้จักรวาลเดิม)

ตั้งเมื่อ 2026-11-16 (Nox). แรงบันดาลใจ: เทรนด์ "In this town / In this world" (กฎประหลาดหนึ่งข้อคุมทั้งเมือง) แต่เล่าแบบเรา: หน้าตาย เวอร์หลุดโลก ปิดแห้ง

## สิ่งที่ล็อกแล้ว
- เสียงพากย์: Gemini TTS เสียง **Rasalgethi** (Nox เลือก 2026-11-16)
- ช่อง: ลงช่องเดิม `@absurd.cases` (Nox 2026-11-16) — HANDLE ใน data.ts
- ภาพ: ระบบเดิม (three.js/Remotion kit, ตัวละครกล่องออริจินัล, mocap, motion blur, premix) **ไม่ใช้ตัวละคร/หน้าตา Roblox** ไม่ใช้โลโก้หรือชื่อ Roblox
- ไม่ใช้ตัวละคร ฉากเฉพาะ ห้องขัง หรือ hook ของ absurd-cases (ใช้โค้ด/ฉากทั่วไปจาก kit ได้ เช่น หมู่บ้าน ถนน ห้อง)
- 1080×1920 @ 30 fps, ผู้บรรยายคนเดียว (Fenrir), BGM เบาๆ

## สูตร
1. บรรทัดแรก = กฎของเมือง: "ในเมืองนี้, ถ้า<เรื่องธรรมดา>, <ผลประหลาด>" — ภาพเฟรม 0 คือกฎกำลังเกิด
2. ตัวเอกทำผิดกฎโดยไม่ตั้งใจ → ผลเกิดจริงทันที
3. หน่วยงานของเมืองจริงจังเกินเหตุ (เทศบาล ประกาศ กล้อง ด่าน หน่วยพิเศษ) — บทเรียนจาก absurd-cases: ไม่มีคนจริงจังมารับมุก = ไม่ตลก
4. ไต่ระดับ 3 ขั้นจนถึงระดับเมือง/โลก/จักรวาล
5. ปิดแห้ง 2–5 คำ (callback / ผลตรงตัว / ต้นเหตุยังอยู่) ไม่ใช่หักมุมซึ้งแบบเทรนด์

## รูปแบบตอน (Nox 2026-11-16: "เล่าเรื่องยาวแบบในตัวอย่าง")
- ยาว ~2 นาที แบบเต็มของเทรนด์ ผู้เล่าบุรุษที่ 1 เป็นเด็กในเมือง ("ฉัน") เล่าหน้าตาย
- โครง: ประโยคแรกฟังไม่น่าจริง → กฎ → ชีวิตใต้กฎ (หน่วยงานเวอร์) → ปลูก 3 อย่าง (ญาติผู้ใหญ่มีอดีต) → ภัยใหม่ที่ทั้งเมืองเฮ มีฉันคนเดียวที่เห็น → หายนะไต่ระดับ → ความลับของผู้ใหญ่ → ฉันใช้ตรรกะของกฎแก้ → ผลเวอร์เกิน → ประโยคแรกพลิกความหมาย → จบที่ภัยถัดไป
- ยังไม่ได้ตัดสิน: จะตัดเป็น Short 30–60 วิ ด้วยไหม

## ไอเดียสำรอง
- พูด "เดี๋ยวทำ" เมื่อไหร่ ตัวคุณอีกคนโผล่มารอทำ → 400 ตัว → ได้ที่นั่งในสภา → "จานยังไม่มีใครล้าง"
- ใครจามแรงสุด บ้านย้ายไปหนึ่งหลัง → ไปรษณีย์ส่งผิดทั้งเมือง → "ตอนนี้บ้านเขาอยู่บนดวงจันทร์"
